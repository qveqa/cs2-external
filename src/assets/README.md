# Иконки оружия

`weapon_icons.h` содержит встроенный CS2GunIcons.ttf.
Автор: [Luuucasss](https://github.com/Luuucasss).
Источник: [Weapon-Icon-CS2](https://github.com/Luuucasss/Weapon-Icon-CS2).
Системные шрифты Windows загружаются во время запуска и не входят в проект.

В исходном репозитории шрифта не указана явная лицензия. Атрибуция здесь
сохраняет сведения об авторе и не заменяет лицензию шрифта.

Сборка без заголовка иконок также поддерживается: тогда остаются текстовые
названия оружия.
